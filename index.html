Project spotlight / MarketFit

From job requirements to an actionable learning plan.

Developed as a collaborative three-member hackathon project, MarketFit is a working end-to-end prototype that helps learners compare the skills employers seek with evidence in their GitHub projects.

01 / Analyze demand

Collect job requirements and identify frequently requested technical skills.

02 / Compare evidence

Review GitHub repositories and project signals to identify demonstrated and missing skills.

03 / Build a path

Generate a personalized 14-day project roadmap, including learning links for the recommended steps.

Future direction: Add verified, publicly available recruiter or hiring-team contact channels for relevant listings, with optional outreach guidance. This feature is planned, not yet implemented.
